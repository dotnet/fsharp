### Breaking Changes

* The F# 18.11 backport uses `FSharp.Compiler.Service` version `43.13.402`, not the `43.12.*` servicing family. ([PR #20725](https://github.com/dotnet/fsharp/pull/20725))
* Third-party FCS consumers must update their source and rebuild. This package is not a binary-compatible replacement for `43.12.*`.
* `FSharpSourceTokenizer` now takes three constructor arguments. Remove the `strictIndentation` argument. `FSharpLexer.Tokenize` also removes this argument.
* Tooltip descriptions, type mappings, remarks, and method parameter displays now use `RichText`, not `TaggedText[]`. Use `RichText.Parts` for classified text.
* Record expressions, anonymous records, and record type definitions now contain field-or-spread nodes. Update record AST construction and pattern matching. `SynExprRecordField` moves its separator to the enclosing node.
* `SynInterpolatedStringPart.FillExpr` now contains `SynInterpolationFormatting`, not `Ident option`. Update interpolation AST construction and pattern matching.
