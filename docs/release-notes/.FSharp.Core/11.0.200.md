### Added

* Add the `GeneratedRuntimeAsyncSequenceBase.Close` and `CompleteMoveNext` compiler-services members for runtime-async sequences; `DisposeAsync` now runs pending `finally` blocks through `MoveNextAsync`. ([PR #20655](https://github.com/dotnet/fsharp/pull/20655))

### Fixed

* Correct `FSharpValue.PreComputeTuplePropertyInfo` to report that struct tuples store elements in fields, not properties, and recommend supported tuple readers instead of reporting a valid index as out of range. ([Issue #20801](https://github.com/dotnet/fsharp/issues/20801), [PR #20815](https://github.com/dotnet/fsharp/pull/20815))
* Quotation debug text from `Expr.ToString()`, `Expr.ToString(full)`, and `%A` now prints struct tuple construction as `NewStructTuple`; reference tuples remain `NewTuple`. ([Issue #20800](https://github.com/dotnet/fsharp/issues/20800), [PR #20814](https://github.com/dotnet/fsharp/pull/20814))
* Fix struct tuples in query expressions: selecting one no longer fails with "unreachable", and the items of one that a later operator reads are taken from its fields instead of failing with `ArgumentException: Struct tuples store their elements in fields, not properties`. ([Issue #15522](https://github.com/dotnet/fsharp/issues/15522), [PR #20894](https://github.com/dotnet/fsharp/pull/20894))
* Fix LINQ providers failing on a `groupBy` or `groupValBy` over tuples or records followed by `select (g.Key, g.Count())`, `g.Sum(..)`, `g.Average(..)` and similar: FSharp.Core no longer rebuilds each group as a `Grouping` of tuples in the middle of the query, and no longer re-projects every element after a `join` or a `for`. ([Issue #47](https://github.com/dotnet/fsharp/issues/47), [PR #20899](https://github.com/dotnet/fsharp/pull/20899))
* Fix a `find` in a nested query over elements that the translation rebuilds, such as `select (c.Name, query { for o in c.Orders do for o2 in c.Orders do find (o.Id < o2.Id) })`: it no longer fails with "Type mismatch when building 'args'". ([PR #20899](https://github.com/dotnet/fsharp/pull/20899))
